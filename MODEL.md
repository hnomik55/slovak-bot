# Модель бота

Коротко: **как бот учит и как он устроен**. Подробности реализации — в `README.md`.

---

## 1. Обучающая модель

Бот закрывает все четыре навыка из плана (`D:\Slovakia\00-plan.md`), потому что
один тренажёр ушами не учит.

| Навык | Как тренирует бот | Где в боте |
|---|---|---|
| Грамматика и слова | 41 урок из твоего тренажёра: 350 заданий четырёх типов | «📚 Уроки» |
| Чтение | текст под уровень + вопросы на понимание | «📖 Чтение» |
| Аудирование | бот озвучивает фразу (TTS), ты пишешь её по памяти | «🎧 Аудирование» |
| Письмо | пишешь по-словацки — ИИ проверяет по правилам и по твоим ошибкам | «✍️ Письмо» |
| Говорение | диалог голосом + тренажёр произношения | «🗣 Говорить» |
| Слова | 847 слов из твоих словарей, интервальное повторение | «🔤 Слова» |

### Цикл одной учебной сессии

```
задание → мгновенный разбор → ошибка в «Мои ошибки» → SRS-карточка → повтор
```

Ключевое: **ошибка не теряется**. Каждая ошибка получает тег
(`diacritics`, `verb_form`, `accusative`, `sa_verb`, `spelling`…), попадает в
таблицу `error_tags`, и по кнопке «🎯 Тренировать ошибки» бот собирает ровно те
задания, где ты уже ошибался. Это работает против твоих реальных слабых мест:
«он → *Nie som*», «roky / rokov», два глагола подряд, потерянная диакритика.

### Гейты

**По умолчанию все уроки доступны сразу** — можно заниматься с любого места и
возвращаться к нужной теме. Пройденные отмечаются ✅, статистика и «Мои ошибки»
работают как раньше.

Строгий режим (урок открывается после 80% на предыдущем) включается одной
строкой в `.env`:

```
STRICT_GATING=1
```

Зачем он может понадобиться: в жёстком режиме новичок не прокликивает всё подряд
и доходит до B1 с нулевой базой. Но если хочется свободы — выключайте.

### Целевая норма

Из твоего плана: **15 минут слов + 20–30 минут урока в день**. Бот держит эту
норму в настройках (`DAILY_MINUTES`), считает серию дней и один раз в день
напоминает (если ты сам не занимался).

## 2. Модель оценки ответа

Три уровня, не два. «Неверно» без объяснения бьёт по мотивации, а «верно» с
прощением опечатки — по точности.

| Результат | Когда | Что делает бот |
|---|---|---|
| ✅ Верно | совпадение без учёта регистра и пунктуации | +2 XP |
| 🟡 Почти (опечатка) | 1–2 символа, либо переставлены слова | +1 XP, показывает эталон |
| 🟡 Почти (диакритика) | совпадение без `á ä č ď é í ĺ ľ ň ó ô ŕ š ť ú ý ž` | называет потерянные буквы |
| ❌ Неверно | всё остальное | объяснение из контента + запись в ошибки |

Диакритика выделена отдельно намеренно: это твоя системная ошибка
(`osemnást` → `osemnásť`), и на русской раскладке её не набрать физически —
поэтому в заданиях «напиши ответ» есть экранная словацкая клавиатура.

## 3. Архитектура

```
D:\Slovakia\                 ← контент (источник истины)
   app/slovencina.html          41 урок, 350 заданий, правила
   slovar/slova-A1|A2|B1.txt    847 слов (TSV)
   урок-01..07                  конспекты уроков
   pisma/*.md                   2 письма + новые слова
   navyky/*.txt                 методички по 4 навыкам
   progress.md                  твои слабые места
        │
        │  python tools/build_content.py
        ▼
D:\Slovakia\bot\data\content.json   ← единый снимок контента
        │
        ▼
   app/handlers/        экраны: меню, уроки, слова, чтение, аудирование,
                        письмо, говорение, тест, прогресс, настройки
   app/trainer.py       движок урока (4 типа заданий + разбор)
   app/scoring.py       модель оценки ответов
   app/srs.py           интервальное повторение (SM-2, укороченный)
   app/content.py       загрузка контента, гейты, прогресс
   app/services/        ai.py (LLM), tts.py (озвучка), stt.py (речь),
                        reminders.py (напоминания), lexicon.py (новые слова)
   app/db.py            SQLite: users, vocab, user_words, lesson_progress,
                        attempts, error_tags, daily_stats, writing, generated
```

**Принцип:** бот не дублирует контент. Ты правишь `D:\Slovakia` — жмёшь
`/admin_reload` — бот пересобирает `content.json` и едет на новых данных.
Тексты уроков, слова и письма берутся из твоих файлов, а не из кода.

## 4. Где ИИ, а где без него

ИИ — только там, где нужна речь, а не арифметика. Всё, что можно посчитать
точно, считается локально: мгновенно, бесплатно и без галлюцинаций.

| Задача | Без ИИ | С ИИ |
|---|---|---|
| Проверка ответа на задание | ✅ | — |
| SRS, статистика, гейты | ✅ | — |
| Объяснение «почему так» | только текст из контента | разбор в двух предложениях |
| Проверка свободного текста (письмо) | ❌ | ✅ + новые слова в карточки |
| Диалог и исправление речи | ❌ | ✅ |
| Текст для чтения, вопросы | ❌ | ✅ |
| Недостающие юниты 8–10 | ❌ | ✅ (`/admin_gen`) |

Без `AI_API_KEY` бот работает на 70% возможностей: уроки, слова, SRS,
мини-тест, ошибки, прогресс, озвучка, распознавание речи.

## 5. Персонализация

Бот знает о тебе:

* **уровень** (A1/A2/B1) — влияет на словарь и сложность текстов;
* **слабые места** — из `progress.md` (8 пунктов) и из твоих же ошибок в боте;
* **историю** — что прошёл, где ошибаешься, какие слова забываешь;
* **темп** — серия дней, норма в минутах, точность за 7 дней.

На этом строится мини-тест: он берёт вопросы из твоих пройденных уроков и
добивает их вопросами по твоим тегам ошибок.
