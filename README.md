# Словчина — Telegram-бот для изучения словацкого

Бот-тренажёр на базе твоего существующего контента в `D:\Slovakia`:
41 урок, 350 заданий, 847 слов, 2 письма, методички по четырём навыкам.

Он **не дублирует** твой контент, а читает его: правишь файлы в `D:\Slovakia` —
жмёшь `/admin_reload` — бот едет на новых данных.

Полное описание обучающей модели и архитектуры — в [MODEL.md](MODEL.md).


```bash

```

## Управление ботом

Бот умеет работать в фоне (без окна терминала) — удобно для ежедневных занятий:

```bash
python tools\botctl.py start     # запустить в фоне
python tools\botctl.py stop      # остановить
python tools\botctl.py status    # что сейчас + хвост журнала
python tools\botctl.py log 40    # последние 40 строк журнала
python tools\botctl.py restart
```

Журнал всегда в `data\bot.log`. Двойной клик по `botctl.bat` — тоже вариант
(аргументы: `start`, `stop`, `restart`, `status`, `log`).

`start.bat` — другой сценарий: запускает бота в текущем окне и сам открывает
`.env` в блокноте, если токен ещё не вписан.

## Что внутри

### Уроки
Четыре типа заданий — ровно как в твоём HTML-тренажёре, тот же движок:

* **выбор ответа** — варианты каждый раз в случайном порядке (правильный не всегда первый);
* **ввод ответа** — с экранной словацкой клавиатурой (`á ä č ď é í ĺ ľ ň ó ô ŕ š ť ú ý ž`), потому что на русской раскладке их нет;
* **сборка фразы** — из кусочков;
* **сопоставление пар** — по очереди переводишь каждое слово.

После каждого ответа — мгновенный разбор: ✅ / 🟡 опечатка / 🟡 диакритика / ❌ неверно,
объяснение, кнопки «🔁 Ещё раз», «❓ Почему?», «🔊» и «➡️ Дальше».

### Слова (SRS)
847 слов из `slovar/slova-A1|A2|B1.txt`. Интервальное повторение (SM-2,
укороченное под цель A2 за 10 недель): 1 → 3 → 7 → 16 → 35 дней.
Оценка четырьмя кнопками: не знаю / с трудом / нормально / легко.
Экспорт в Anki одной кнопкой (TSV, разделитель табуляция).

### Письмо
Задания из `pisma/*.md` (письмо в TUKE, письмо в UNIZA) + генерация под тему.
Проверка возвращает оценку, каждую ошибку с правилом и тегом, исправленный текст
и новые слова — новые слова сразу попадают в карточки SRS.

### Говорение
Диалог голосом: ИИ говорит по-словацки, ты отвечаешь голосом, речь
распознаётся локально (faster-whisper), ответ приходит с мягкой правкой.
Отдельный тренажёр произношения: бот произносит фразу, ты повторяешь, он
сравнивает и даёт процент совпадения.

### Аудирование и чтение
Аудирование: бот озвучивает фразу из твоих уроков (edge-tts), ты пишешь её по
памяти, бот оценивает. Чтение: ИИ готовит текст под твой уровень с переводом
и вопросами на понимание.

### Мои ошибки
Каждая ошибка получает тег (`diacritics`, `verb_form`, `accusative`,
`locative`, `genitive`, `future`, `spelling`, `extra_words`…). Бот показывает
статистику по тегам и собирает «тренировку ошибок» из конкретных заданий,
где ты уже ошибался.

## Два режима работы

| | `MODE=polling` (по умолчанию) | `MODE=webhook` |
|---|---|---|
| Как работает | бот сам спрашивает Telegram | Telegram шлёт апдейты на твой URL |
| Нужен постоянный процесс | **да** (ПК или VPS) | нет — просыпается на запрос |
| Где бесплатно | ПК с автозагрузкой | PythonAnywhere, Render, Railway, Fly.io |
| Подходит для | учёбы вечером за включённым ПК | «бот онлайн всегда» |

Переключение — одна строка в `.env` + регистрация вебхука:

```bash
python tools/set_webhook.py set https://твой-домен.рф
```

Пошаговая инструкция для бесплатного PythonAnywhere — в
[`deploy/pythonanywhere.md`](deploy/pythonanywhere.md).

## GitHub: что он даёт и что не даёт

GitHub — хостинг кода, а не хостинг ботов. Бот, запущенный в GitHub Actions,
не будет работать бесплатно постоянно:

| | Цифры |
|---|---|
| Бесплатные минуты Actions (приватный репозиторий) | 2 000 мин/мес |
| Сколько нужно боту при работе 24/7 | 43 200 мин/мес |
| Превышение лимита | в 21 раз |

В публичном репозитории Actions бесплатны, но непрерывная работа 24/7 нарушает
правила использования GitHub, одна задача ограничена 6 часами, а workflow без
коммитов отключается через 60 дней. Технический нюанс: Telegram хранит
непрочитанные обновления 24 часа, так что «часовой» бот сработал бы — но с
задержками, и напоминание в 21:00 пришло бы в полночь.

**Зато GitHub полезен по-другому:**

1. **Страховка кода** — ничего не потеряется, есть история изменений.
2. **CI** — тесты (77 проверок) гоняются на каждом пуше, `.github/workflows/tests.yml`.
3. **Автодеплой** — `bash deploy/deploy.sh user@server` кладёт код на VPS и
   перезапускает systemd-сервис.
4. **Контент в репозитории** — `data/content.json` весит 0,37 МБ, сервер всегда
   получает свежую версию. PDF-учебники (447 МБ) в git не кладём: там чужие
   авторские права, и они боту не нужны.

Если GitHub нужен именно как хостинг — есть бесплатные варианты «навсегда»:
Oracle Cloud Always Free (2 бесплатных VM, но регистрация с картой и капчами),
Railway ($5/мес кредита — боту хватит с запасом), Render/Koyeb (засыпают после
15 минут простоя, просыпаются за 30–60 секунд). Предсказуемее всего — VPS за
3–5 €.

## Развёртывание

### Вариант 1: на своём ПК (бесплатно, но комп должен быть включён)

```bash
python tools\botctl.py start     # в фоне, без окна
python tools\install_autostart.py install   # автозапуск при входе в Windows
```

Пока комп включён — бот отвечает. Усыпишь или выключишь — замолчит.

### Вариант 2: VPS (бот работает 24/7, ПК может быть выключен)

Подойдёт любой дешёвый Linux-сервер (Hetzner, Timeweb, Contabo — от ~3–5 €/мес).
Положить бота можно одним скриптом:

```bash
# на сервере
scp -r bot user@server:/tmp/slovak-bot
ssh user@server 'bash /tmp/slovak-bot/deploy/install.sh'
```

Скрипт создаст пользователя, venv, поставит зависимости, скопирует `.env`,
соберёт контент и включит systemd-сервис `slovak-bot`.

```bash
systemctl status slovak-bot     # статус
journalctl -u slovak-bot -f     # живые логи
systemctl restart slovak-bot    # перезапуск
```

Готовый `deploy/slovak-bot.service` и `deploy/Dockerfile` (для Railway/Fly.io/любого
Docker-хостинга) лежат в папке `deploy`.

⚠️ На сервере папки `D:\Slovakia` нет: контент собирается на твоём ПК
(`python tools\build_content.py`) и просто копируется вместе с ботом.
Команда `/admin_reload` на сервере честно скажет об этом.
