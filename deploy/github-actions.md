# Бот в GitHub Actions — бесплатно и постоянно

Так же, как сработал бот по курсу «Евро»: код лежит в GitHub, а сам бот
**просыпается по расписанию**, забирает накопленные сообщения Telegram,
отвечает и выключается. Снаружи он выглядит как обычный постоянно работающий бот.

## Почему это бесплатно

В **публичном** репозитории минуты GitHub Actions не тарифицируются вообще.
В приватном даётся 2 000 минут в месяц, а боту на работу 24/7 нужно 43 200 —
то есть лимит превышается в 21 раз. Поэтому репозиторий должен быть публичным.

Что важно знать про публичный репозиторий:
* код видят все — но в коде нет секретов (токен лежит в Secrets репозитория);
* `.env` в репозиторий не попадает (он в `.gitignore`);
* учебники и PDF туда тоже не кладутся — там чужие авторские права, боту они не нужны.

## Как Telegram это терпит

Telegram хранит непрочитанные обновления **24 часа**. Поэтому бот, который
просыпается раз в 5 минут, получает все сообщения — просто отвечает на них
с задержкой. Практически это значит: ответ приходит через 0–5 минут вместо
мгновенного.

Если нужны мгновенные ответы — держи бота на ПК (режим `polling`, автозапуск
уже настроен). Оба режима одновременно работать не могут: Telegram разрешает
только один поток `getUpdates` на токен.

## Настройка (один раз)

### 1. Создай публичный репозиторий

На github.com → **New repository** → имя (например `slovak-bot`) →
**Public** → **Create repository** (без README — репозиторий должен быть пустым).

### 2. Залей код

На ПК в папке `D:\Slovakia\bot`:

```bash
git init
git add .
git commit -m "Slovencina: telegram-бот для словацкого"
git branch -M main
git remote add origin https://github.com/<твой-логин>/slovak-bot.git
git push -u origin main
```

Если Git ещё не установлен — поставь Git for Windows или GitHub Desktop
(через браузер) и выполни те же команды. `git` также ставится одной командой:

```powershell
winget install --id Git.Git -e --source winget
```

### 3. Добавь секрет

**Settings → Secrets and variables → Actions → New repository secret**:
* `BOT_TOKEN` — токен от @BotFather;
* `ADMIN_IDS` — твой id (8636653095), чтобы работали `/admin_reload` и `/admin_gen`;
* `AI_API_KEY` — ключ ИИ (необязательно).

### 4. Включи Actions

Вкладка **Actions** → workflow **slovak bot** → **Run workflow** (проверка вручную).
Дальше он будет запускаться сам каждые 5 минут по расписанию `*/5 * * * *`.

### 5. Проверь

Открой бота в Telegram → `/start`. Ответ придёт в пределах 5 минут.
Логи каждого запуска — вкладка **Actions → slovak bot → Run → logs**.

## Как хранится твой прогресс

БД (пройденные уроки, карточки слов, ошибки, серия дней) лежит в `state/slovak.db`
и после каждого запуска коммитится обратно в репозиторий. Поэтому прогресс
не теряется между запусками.

Чтобы обновить контент после правок в `D:\Slovakia`:

```bash
python tools\build_content.py
git add data/content.json
git commit -m "контент: новая версия"
git push
```

Следующий запуск подхватит свежий контент.

## Подводные камни (честно)

| Проблема | Что будет | Что делать |
|---|---|---|
| Ответы с задержкой 0–5 мин | норма для этого варианта | для мгновенных ответов — ПК |
| Scheduled workflow отключается после 60 дней без коммитов | бот замолчит | раз в месяц нажми **Run workflow** вручную или запуш любой коммит |
| Публичный репозиторий | код видят все | в коде нет секретов, это нормально |
| `git push` может не пройти при конфликте | прогресс этого запуска не сохранится | запусти вручную ещё раз |
| GitHub может задерживать cron в пиковые часы | бывает задержка до 15 минут | это редкость |

## Если хочется без задержек и без своего ПК

Тогда режим `webhook` + любой бесплатный веб-хостинг (PythonAnywhere, Render,
Railway) — бот отвечает мгновенно. Инструкция в
[`pythonanywhere.md`](pythonanywhere.md). Код тот же самый, меняется только
`MODE=polling` → `MODE=webhook` в `.env`.
