# Mini App: приложение внутри Telegram

Кнопка **«📱 Открыть приложение»** в меню бота открывает веб-приложение прямо
в Telegram. Внутри — всё, что есть в боте: уроки, слова, прогресс, ошибки,
мини-тест, тренировка ошибок, озвучка.

Чат и приложение работают с одной базой: пройденный урок в чате виден
в приложении и наоборот.

---

## Как это устроено

```
Telegram ──▶ Mini App (miniapp/index.html)  ──▶ /api/*  ──▶ Flask
                                                         ├── SQLite (общая с чатом база)
                                                         ├── оценка ответов (server-side)
                                                         └── TTS (озвучка)

Telegram ──▶ бот в чате (aiogram, polling)  ──▶ та же SQLite
```

* Фронтенд — один файл `miniapp/index.html` (без сборки).
* Бэкенд — `app/miniapp_api.py` + `app/webhook_app.py` (Flask).
* Авторизация: Telegram подписывает данные пользователя, бот проверяет подпись
  HMAC-SHA256 (`app/miniapp_auth.py`). Правильные ответы в приложение не
  уходят — оценкаalways на сервере.

## Запуск (на твоём ПК)

```bash
cd D:\Slovakia\bot
python tools\miniapp_tunnel.py start
```

Скрипт:
1. поднимает сервер приложения на порту 8000;
2. поднимает Cloudflare Tunnel и получает публичный адрес
   `https://<случайное>.trycloudflare.com`;
3. прописывает его в `.env` как `WEBAPP_BASE_URL`;
4. перезапускает бота — кнопка «Открыть приложение» появляется в меню.

Остановить: `python tools\miniapp_tunnel.py stop`.
Проверить: `python tools\miniapp_tunnel.py status`.

### Важно про адрес

Адрес quick-туннеля **меняется при каждом перезапуске**. Пока адрес не
прописан в `.env`, кнопка в боте ведёт в никуда. Решение: запускай
`miniapp_tunnel.py start` после каждой перезагрузки компьютера.

Для постоянного адреса нужен либо именованный туннель Cloudflare (нужен
аккаунт Cloudflare), либо бесплатный хостинг из `deploy/pythonanywhere.md`
(там адрес постоянный).

## Автозапуск вместе с ботом

```bash
python tools\install_autostart.py install
```

Кнопка автозагрузки поднимает и бота, и приложение с туннелем.

## Вход из обычного браузера

Чтобы смотреть приложение не в Telegram, а в браузере (для отладки), в `.env`:

```
APP_DEV=1
DEV_TELEGRAM_ID=8636653095
```

Тогда запросы без initData принимаются за этого пользователя.
**В продакшене поставь `APP_DEV=0`** — иначе любой, кто знает адрес,
сможет ходить в приложение под твоим именем.

## Что работает в приложении

| Раздел | Что умеет |
|---|---|
| 📚 Уроки | карта из 41 урока, 4 типа заданий, мгновенный разбор, 🔊 озвучка |
| 🔤 Слова | SRS-карточки, 4 оценки, счётчик на повторении |
| 📊 Прогресс | XP, серия, точность, 7 дней, юниты, ошибки по тегам |
| ⚠️ Мои ошибки | теги ошибок, последние ошибки |
| 📝 Мини-тест | 10 вопросов из пройденных уроков |
| 🎯 Тренировка ошибок | подборка заданий, где ты уже ошибался |

Письмо, чтение и разговор с ИИ работают, когда включён `AI_API_KEY`;
иначе приложение сообщит, что нужен ключ.

## Тесты

```bash
python tests\test_miniapp.py   # 50 проверок API: авторизация, оценка, SRS, утечки ответов
```
