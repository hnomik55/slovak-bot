# Облачный режим: бот в GitHub Actions

> **Вердикт по факту замеров: для чат-бота не годится.**
> GitHub запускает cron у публичных репозиториев раз в **46–82 минуты**
> (замерено: интервалы 46, 57, 60, 63, 64, 65, 76, 82 мин). Бот просыпается,
> отвечает на накопленные сообщения и засыпает. Для учебника с кликами по
> заданиям задержка в час неприемлема.
>
> Схема остаётся в репозитории (`deploy/bot-actions.yml.disabled`) как
> запасной вариант «бот работает без ПК, но отвечает редко» — чтобы принимать
> ключи активации, пока тебя нет у компьютера.
>
> **Что реально работает всегда — PythonAnywhere**, инструкция в
> `pythonanywhere_setup.md`: бот в webhook-режиме, API и приложение там же,
> твой ПК не участвует.

Чтобы бот отвечал, когда твой ПК выключен, чат-бот переезжает в GitHub Actions.

## Как это устроено

```
каждые 3 минуты → GitHub запускает бота → бот забирает накопленные сообщения
                → отвечает → через 3,5 минуты выключается → сохраняет прогресс в репозиторий
```

* Минуты Actions в **публичном** репозитории не тарифицируются (в приватном
  лимит 2 000 мин/мес, а боту на 24/7 нужно 43 200).
* Telegram хранит непрочитанные сообщения 24 часа, поэтому ничего не теряется.

**Цена: ответ приходит с задержкой 0–5 минут** (обычно 2–3). Для разговорной
практики это неудобно — тогда лучше держать бота на ПК.

## Что где живёт

| Часть | Где | Без ПК |
|---|---|---|
| Чат-бот (уроки, слова, ошибки) | GitHub Actions | ✅ работает |
| Прогресс, слова, ошибки | `state/slovak.db` в репозитории | ✅ |
| Mini App (приложение) | GitHub Pages | ✅ страница открывается |
| API Mini App (данные, оценки) | твой ПК через туннель | ❌ нужен ПК |

**Важно:** приложение в Telegram откроется всегда, но когда ПК выключен, оно
не сможет загружать данные — API живёт на ПК. Чтобы и приложение работало
24/7, нужен любой бесплатный Python-хостинг (PythonAnywhere, Render) —
инструкция в `pythonanywhere.md`.

## Чего делать нельзя

Запускать локального бота и облачного одновременно: Telegram разрешает только
один поток `getUpdates` на токен, и второй экземпляр будет получать
«terminated by other getUpdates request». Режим переключается командой
`tools/bot_mode.py`.

## Проверка

```bash
python tools\botctl.py status          # локальный бот
python tools\bot_mode.py status        # текущий режим
```

В GitHub: вкладка **Actions** → **slovak bot** → последние запуски. Если
видишь «BOT_TOKEN не задан в Secrets» — секрет не добавлен.
